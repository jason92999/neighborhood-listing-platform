# Neighborhood Property Listing Platform

A simple website for finding property listings and learning about neighborhood sponsors.

## Features

* Property Listings
* Neighborhood Sponsors
* Voice Help

## Built With

* Next.js
* TypeScript
* Tailwind CSS
